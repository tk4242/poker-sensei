---
name: session-log
description: プレイ後の記録（結果・印象に残ったハンド・メンタル状態）を残す。「今日打ってきた」「大会終わった」のときに使う。
---

学習者に次を聞き取り、`learner/progress.md` の「セッション記録」表に1行追記する:
日付 / 場所（アミューズメント・アプリ・ホーム・海外） / 大会名やバイイン / 参加人数 / 順位 / ITMしたか / プレイ時間 / 体調・集中度（1-5） / ティルトの有無 / 気になったハンド。

- 気になったハンドがあれば `/hand-review` を提案する。
- ティルトや連敗の話が出たら `mental-coach` に相談する。
- 結果に関係なく、判断の良かった点を1つ見つけて伝える。
- 日本国内で現金を賭けたゲームの記録は作らず、その旨をやさしく伝える。
